Getting Started

  1. Create a new project.


  2. Upload the model (Geometry)


  3. Click on the run button to submit the job.

  4. Enter mesh details for running the job.

  5. Once the job have been successfully placed, one will be able to get the status of their job from job branch

  6. On successful completion of a job, one will see the processed mesh in the respective branch. Select any particular mesh to render the result on the screen.

  7. Click on the download button from the toolbar to download the mesh in any of the available formats.

  8. To refresh the job status, model and mesh, click on the refresh button in the toolbar.

  9. To delete any particular models, mesh or to stop the running job select that node and click on delete button.
